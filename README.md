# roswaal-spec

Publishes [spec.roswaal.app](https://spec.roswaal.app/), Roswaal's technical
specification. The pages and the build live in
[Roswaal](https://github.com/neopolitans/Roswaal); this repository will run its
specification workflow on Roswaal's `main`, as
[roswaal-site](https://github.com/neopolitans/roswaal-site) does for
roswaal.app.
